# Teacher Assignment & Class Teacher Rules

## Assign Modal Form Controls
1. **Class**: Dropdown `1st` to `12th` / `1` to `12`.
2. **Section**: Dropdown `A`, `B`, `C`, `D`.
3. **Subject**: Text input.
4. **Class Teacher Checkbox**:
   - Dynamically disable if Class + Section already has a Class Teacher assigned.
   - Display tooltip/badge: "Class Teacher already assigned to <Name>".

## Access Scope
1. **Subject Teacher**: Scope restricted to assigned subject.
2. **Class Teacher**: Full Class Scope — view test results, rank lists, and test progress for ALL subjects in assigned class & section.
