# Shared Paper Repository & Classwise Folder Rules

## Folder Hierarchy & Naming
1. **Base Path**: `paper/Class_<N>/Section_<X>/`
2. **File Naming Format**:
   `<class>_<section>_<subject>_<examtype>_<TeacherName>.doc`
   - Example: `10_A_Mathematics_UnitTest_Gaurav_Shukla.doc`
   - Example: `8_B_Science_HalfYearly_Anjali_Sharma.doc`
3. **Sharing Rule**:
   - All generated `.doc` files are saved into this folder structure automatically.
   - All teachers have download & browse access to this repository for cross-teacher test paper sharing and reuse.
